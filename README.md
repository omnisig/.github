# .github

Organization-level defaults and brand assets for **omnisig**.

> **omnisig** — one Ethereum multisig, control on any destination chain.

## Contents

- [`brand/`](brand/) — the omnisig icon (SVG source + rasterized PNGs), palette, and
  usage. See [`brand/README.md`](brand/README.md).

To use the mark as the org avatar, upload `brand/omnisig-icon-512.png` at
**Settings → Profile → Profile picture** (avatars are upload-only).
